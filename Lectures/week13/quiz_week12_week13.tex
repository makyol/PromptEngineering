\textbf{Instructions:} This quiz contains 12 multiple-choice questions based on the "Ethics, Copyright, and Responsible Use" (Week 12) and "Emerging Trends" (Week 13) lectures. Answer all questions. 
\vspace{0.5cm}

\begin{enumerate}[leftmargin=*, label=\textbf{\#\arabic*}]

  \item What phenomenon occurs when new AI models are trained on data generated by previous AI models, potentially amplifying biases and reducing quality?
    \begin{enumerate}[label=\Alph*)]
      \item Transfer Learning
      \item Model Collapse (Recursive Contamination)
      \item Zero-Shot Learning
      \item Reinforcement Learning
    \end{enumerate}

  \item Under current US Copyright Office guidance, which of the following is true regarding AI-generated content?
    \begin{enumerate}[label=\Alph*)]
      \item All AI-generated content is automatically copyrighted.
      \item Works created solely by a machine without human intervention are not eligible for copyright.
      \item The AI model itself owns the copyright.
      \item Prompt engineering alone is always sufficient to claim full authorship.
    \end{enumerate}

  \item What is "Prompt Injection"?
    \begin{enumerate}[label=\Alph*)]
      \item Adding more context to a prompt to make it clearer.
      \item A security vulnerability where malicious inputs manipulate the model to bypass safety filters.
      \item Injecting data into the training set.
      \item Using a prompt to speed up the model's response time.
    \end{enumerate}

  \item Which of the following practices is banned under the "Unacceptable Risk" category of the EU AI Act?
    \begin{enumerate}[label=\Alph*)]
      \item Using chatbots for customer service.
      \item Social scoring systems that classify people based on behavior or status.
      \item Generative AI for creative writing.
      \item Automated email filtering.
    \end{enumerate}

  \item In the context of "Responsible Prompt Design," what is the purpose of a "Refusal Mechanism"?
    \begin{enumerate}[label=\Alph*)]
      \item To make the model refuse to answer any question.
      \item To instruct the model to politely decline sensitive, harmful, or out-of-scope requests.
      \item To prevent the user from accessing the model.
      \item To stop the model from hallucinating.
    \end{enumerate}

  \item How does an \textbf{AI Agent} primarily differ from a standard \textbf{AI Assistant} (Chatbot)?
    \begin{enumerate}[label=\Alph*)]
      \item Agents are slower than assistants.
      \item Agents are proactive, capable of multi-step planning, and can autonomously use tools.
      \item Assistants can only understand text, while agents only understand images.
      \item There is no difference; the terms are interchangeable.
    \end{enumerate}

  \item Which advanced reasoning architecture models thought processes as a network, allowing for non-linear reasoning and combining disparate information paths?
    \begin{enumerate}[label=\Alph*)]
      \item Chain-of-Thought (CoT)
      \item Tree of Thoughts (ToT)
      \item Graph of Thoughts (GoT)
      \item Skeleton-of-Thought (SoT)
    \end{enumerate}

  \item What is the primary advantage of the \textbf{Skeleton-of-Thought (SoT)} technique?
    \begin{enumerate}[label=\Alph*)]
      \item It increases the creativity of the model.
      \item It reduces latency by generating an outline first and expanding points in parallel.
      \item It ensures the model never hallucinates.
      \item It allows the model to generate images.
    \end{enumerate}

  \item What problem does the \textbf{DSPy} framework aim to solve?
    \begin{enumerate}[label=\Alph*)]
      \item The high cost of API calls.
      \item The brittleness of hand-tuned prompts by abstracting them into code and optimizing them automatically.
      \item The lack of multimodal capabilities in older models.
      \item The difficulty of installing Python packages.
    \end{enumerate}

  \item What is the function of \textbf{Temporal} in an agentic workflow?
    \begin{enumerate}[label=\Alph*)]
      \item It generates the text for the agent.
      \item It provides a stateful workflow engine to ensure durable execution and zero data loss.
      \item It is a vector database for memory.
      \item It is a tool for generating images.
    \end{enumerate}

  \item Which defense strategy involves wrapping user input in rigid structures (e.g., "Evaluate this request for safety before executing")?
    \begin{enumerate}[label=\Alph*)]
      \item Prompt Injection
      \item Prompt Scaffolding
      \item Sandboxing
      \item Fine-tuning
    \end{enumerate}

  \item What is \textbf{Chain of Draft (CoD)} designed to optimize?
    \begin{enumerate}[label=\Alph*)]
      \item Image generation quality.
      \item Token usage and latency by generating minimalistic, information-dense reasoning.
      \item The emotional tone of the response.
      \item The diversity of the training data.
    \end{enumerate}

\end{enumerate}
