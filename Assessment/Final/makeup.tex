% ============================================== mechanism
\q{Which is the single operation underlying everything a large language model produces?}
  {Matching the question against a database of answers}
  {Predicting the next token, repeatedly}
  {Executing rules supplied by developers}
  {Summarising retrieved web pages}

\q{Why is the model unable to signal when it is guessing?}
  {Guessing is suppressed by safety training}
  {The same operation runs whether the pattern is strong or weak, and confidence is not part of the output}
  {Confidence scores exist but are hidden by the interface}
  {Users have disabled the feature}

\q{A model is asked about a regulation amended after its knowledge cut-off. What is most likely?}
  {It reports that its knowledge ends at a specific date}
  {It answers confidently using the earlier version or something adjacent}
  {It refuses to answer}
  {It searches for the update automatically}

\q{Tokenisation explains all of the following \textbf{except}:}
  {Difficulty counting letters within a word}
  {Inconsistent behaviour of word-count instructions}
  {Higher cost for Turkish text than English}
  {The tendency to accept a false premise in a question}

\q{Which word is most likely to be split into several tokens?}
  {and}
  {patient}
  {an uncommon Turkish word built from several suffixes}
  {the}

\q{What happens when a document exceeds the context window in the most dangerous case?}
  {The service returns an explicit error}
  {Part of the material is dropped silently and a confident answer follows}
  {The answer is visibly cut off}
  {The model asks for a shorter document}

\q{Which statement about fine-tuning for safety is accurate?}
  {It installs a rule that blocks disallowed output}
  {It shifts probabilities, producing a tendency rather than a guarantee}
  {It removes disallowed material from training data}
  {It applies only to images}

\q{Two colleagues get different answers to an identical prompt. The best explanation is:}
  {One of them used a different model}
  {Randomness in token selection}
  {One prompt contained a typographical error}

\q{Which lever should be pulled when the output assumes the wrong reader or the wrong country?}
  {Format}
  {Examples}
  {Context}
  {Temperature}

\q{Which is the strongest reason for asking a model to quote its supporting sentence?}
  {It shortens the answer}
  {It converts an unverifiable claim into one you can check in seconds}
  {It prevents hallucination}
  {It reduces token cost}

\q{Why is ``make it more professional'' an unreliable instruction?}
  {The model does not recognise the word}
  {It describes a feeling rather than a text, and many different outputs satisfy it}
  {It conflicts with safety training}
  {It requires more tokens than the alternatives}

\q{In the three dimensions of register, \textbf{mode} refers to:}
  {The subject vocabulary}
  {The relationship between writer and reader}
  {The channel --- written to be read, written to be spoken, planned or spontaneous}
  {The level of formality}

\q{Why does specifying a fallback string reduce invented content?}
  {It lowers the temperature}
  {It gives the honest answer a fixed and probable form}
  {It blocks access to training data}
  {It shortens the response}

  {Fabrication}

   is:}

\q{What is common to every failure mode covered in this course?}
  {They require long conversations}
  {They are invisible in the output}
  {They affect only grounded systems}
  {They can be eliminated by better prompts}

\q{Which is genuine verification of a factual claim?}
  {Asking the model how confident it is}
  {Asking the same question a second time}
  {Locating the claim in a source you trust}
  {Asking the model to double-check its work}

\q{A generated tool works on the inputs you tried and fails on an empty field. Which failure is

\q{Why is a consistently wrong generated tool more dangerous than an intermittently wrong one?}
  {It uses more resources}
  {Consistency resembles reliability, so the error is not noticed}
  {It is harder to regenerate}
  {It fails at higher volumes}

  {Source selection}

  {77\%}

  {It is a judgment about matching an intention that is not in the context, so it is predicted like anything else}

\q{Which is the most robust control over an agent's behaviour?}

  {A request that it explain its reasoning}
